공통 사항

기본 URL — https://{서버 주소} 아래에서 서비스별 접두로 접근합니다. 각 문서에 표기된 경로가 이미 접두를 포함한 실제 호출 경로입니다.

인증 — POST https://{서버 주소}/auth/api/v1/auth/login 으로 받은 accessToken 을 Authorization: Bearer {token} 헤더에 담아 보냅니다. 토큰은 기본 10분 후 만료되며 /auth/api/v1/auth/refresh 로 갱신합니다.

시간 형식 — 모든 시각은 RFC 3339 (UTC), 예: 2026-08-30T09:00:00Z
